Start here

Install Kriko. Check your first product.

Start with a free catalog lookup. No Kriko account, AI key or research bill is needed for installed catalogs.

1. Install the Windows app.

For Windows on an x64 computer. The installer includes the engine and needs no separate Python installation or administrator rights.

Download Kriko for Windows

Prefer a portable ZIP? Extract the entire archive before opening Kriko.

The installer is currently unsigned, so Windows may show a publisher warning. Download only from the official release linked here. Check the file against the release checksums before deciding whether to run it.

Official SHA-256 checksums · Release notes and all files

How do I verify the download?

In PowerShell, run this command with the path to the file you downloaded. Compare its hash with the matching filename in the official checksums.

Get-FileHash -Algorithm SHA256 .\kriko-0.3.8-x86_64-setup.exe

If the hashes differ, do not run the file. Download it again from the official release.

2. Install a catalog. No AI key needed.

Open Kriko, then More → Catalogs → Find release catalogs. Install a catalog for the products you want to check. The installer starts without catalogs.

Installed catalog lookups work offline. You can also read sourced product reports on this website without installing anything.

3. Add the browser extension.

Keep the desktop app running. Install Kriko from the Chrome Web Store in Chrome, Edge or Brave. The extension needs the app to perform checks.

4. Check one listing and open a source.

Open a product listing. Press the Kriko toolbar button or Alt + K. Confirm the model and variant. Read one finding and open its source before deciding what to ask the seller.

No findings means a gap in coverage. It does not prove that a product is trouble-free.

See each step in the guide

Want to research beyond a catalog?

Open More → Agents, choose an agent and press Check connection. Online research needs internet access and a connected provider. Paid providers bill your own account.

If the extension cannot connect

Open the desktop app and keep it running. Open More → Set up Kriko and check the browser connection. Allow access to the listing site when the extension asks.

Using macOS, Linux or a phone?

The published desktop download is for Windows x64. Apple Silicon macOS can be built from source. The Android app is a test build. You can read all public product reports in your browser.

macOS source instructions · Android test build · Browse known problems

Need help?

Report an installation problem with the app version and error message. Keep API keys and private listing details out of the report.

A little research goes a long way.
