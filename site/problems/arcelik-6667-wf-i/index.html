Costly or dangerous

E20 error code and failure to take in water

Same owner reports an E20 error code and the machine failing to draw water, alongside the drying and Wi-Fi faults.

What to check. E20 is a water-intake fault; combined with the other complaints it suggests this unit had multiple systemic faults. Ask a seller about the E20 code and water-intake history before buying.

Reported on: sikayetvar.com

Persistent wet dishes and drying function disabled after service adjustment

Owner reports dishes always come out wet, and after a service visit the automatic door-opening and extra-drying functions stopped working.

What to check. The drying complaint recurs across owners; a service visit may itself disable the auto door-opening drying feature, so check it after any repair.

Reported on: sikayetvar.com

Wet dishes even on intensive 70°C + extra drying program

Owner reports dishes remain wet even on the intensive 70°C program with extra drying, after multiple service visits.

What to check. If you need reliable drying, verify the extra-drying function actually works before buying; this is the most repeated complaint on this model.

Reported on: sikayetvar.com

Wi-Fi main card replaced three times, never pairs with the unit

The Wi-Fi main card was replaced three times and still never paired with the machine; the owner ultimately got a refund.

What to check. The Wi-Fi module on this model is a recurring electrical failure that multiple card swaps did not fix; if you buy it, test Wi-Fi pairing immediately and be prepared to push for a replacement or refund.

Reported on: sikayetvar.com

WiFi main card burned out three times, never paired; E20 water intake error

Owner complaint from July 2025 on Şikayetvar reporting the WiFi main card burned out and was replaced three times without ever pairing with the device, plus drying not working and intermittent E20 error code for water intake failure. This came from the search query 'Arçelik 6667 WF I arıza'.

What to check. The WiFi main board is a recurring electrical failure point on this model; if the smart features matter, expect possible repeated service visits. The E20 error indicates a water intake fault that also recurred.

Reported on: sikayetvar.com

Worth checking

Dishes come out dirty and spotty despite repeated service visits

Owner reports dishes come out dirty and spotty, five service visits found 'no problem', and he was told to use only the intensive program.

What to check. Cleaning complaints on this model were dismissed by service as user error; if you buy it, run a normal program early to verify cleaning quality before the return window closes.

Reported on: sikayetvar.com

New unit stopped running two minutes into a normal program

A brand-new unit would not run at all, then stopped two minutes into a normal program.

What to check. A new unit failing to run points to an electronics/control fault; verify the machine completes a full cycle right after installation.

Reported on: sikayetvar.com

Wi-Fi connection cannot be established

The same owner could not connect the machine's Wi-Fi at all and got no solution.

What to check. Wi-Fi connectivity problems appear on this model in multiple independent complaints, so treat the smart features as unreliable rather than a selling point.

Reported on: sikayetvar.com

Minor

Unit delivered damaged twice, replacement request delayed

Owner reports the unit was delivered damaged, then a replacement was also delivered damaged, with the exchange process dragged out.

What to check. Inspect the delivered unit carefully on arrival and photograph any damage immediately, since damaged deliveries and slow exchanges are reported on this model.

Reported on: sikayetvar.com
