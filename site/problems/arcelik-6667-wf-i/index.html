E20 error code and failure to take in water

Serious

Same owner reports an E20 error code and the machine failing to draw water, alongside the drying and Wi-Fi faults.

What to checkE20 is a water-intake fault; combined with the other complaints it suggests this unit had multiple systemic faults. Ask a seller about the E20 code and water-intake history before buying.
