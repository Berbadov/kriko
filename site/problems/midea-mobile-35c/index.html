Independent confirmation of the Mobile 35C fire-risk recall (Austrian consumer portal)

SeriousSafety risk

The Austrian consumer-protection portal vki.at independently republishes the same recall with the identical fire mechanism, confirming the manufacturer notice is not an isolated page.

What to checkThis second independent source confirms the recall is real and widely published. Treat any 2019 Mobile 35C as potentially affected and verify the serial number before running it.

Reported onvki.at

Worth checking1

Midea's own error-code table: E1 room-sensor and E2 evaporator-sensor failures on portable units

To check

Midea's official support FAQ documents that its portable air conditioners throw E1/E2 codes for room and evaporator temperature sensor failures; a repair-shop source (smartfehler.de) confirms the same E1/E2 mapping specifically for the Mobile 35C platform.

What to checkIf the unit shows E1 or E2, the temperature sensor is the likely failed part; Midea advises checking for obstructions, restarting, and if the code persists, unplugging and calling service. Sensor replacement is the typical fix.

Reported onmidea.com

Minor3

Midea Mobile 35C E2 error code = evaporator temperature sensor fault

Minor

According to the official Midea manual for the Mobile 35C platform, error code E2 indicates a fault in the evaporator temperature sensor (E1 = room temperature sensor). This is useful for an owner troubleshooting an E2 display on this specific model, and the source warns that older generic guides mislabel E2 as the room sensor.

What to checkIf the unit shows E2, first check that air intake/outlet are unobstructed and restart; if the error persists, stop use and contact the manufacturer or a qualified technician rather than opening the unit.

Reported onsmartfehler.de

Midea Mobile 35C WiFi connection drops intermittently; app reported as poor

Minor

Owner reviews on digitec report the unit intermittently losing WiFi connection and describe the companion app as not usable, though the unit itself cools and runs fine. This is a low-severity reliability/connectivity complaint, not a safety issue.

What to checkIf remote control via app matters to you, expect possible WiFi dropouts; the unit still operates via its IR remote. This is a minor convenience issue, not a reason to avoid the model on safety grounds.

Reported ondigitec.ch

Owner reports: Mobile 35C WiFi/app control unreliable, connection drops

Minor

Owner reviews on digitec/galaxus report the WiFi connection drops periodically and the companion app is not usable; a Symcon home-automation thread shows users struggling to get the Mobile 35C's API token, corroborating weak connectivity control.

What to checkExpect the smart-control features to be flaky; if you only need basic cooling, the unit works, but do not rely on app-based scheduling or remote control.

Reported ondigitec.ch
