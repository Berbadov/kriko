E:01 overflowing warning signals a leak or excess water intake (DIS15022)

To check

This is Beko's own manual for the DIS15022 documenting the E:01 overflowing error code: the machine detects excess water intake or a leak and flashes E:01. If the code does not clear, the manual says there is a permanent fault requiring authorised service. This is the documented fault path for a water leak on this model.

What to checkIf a DIS15022 flashes E:01, the machine is detecting a leak or excess water intake. If the code clears on its own the safety algorithm has discharged the water; if it persists, the manual directs you to contact authorised service, which implies a paid repair visit.

Loose door lock wiring connector stops DIS15022 from starting any cycle

To check

This is an owner's own repair record on the exact DIS15022 model: a loose door-lock wiring connector inside the door panel made the machine read the door as permanently open, so it powered on but refused to start any programme. The reset procedure in the thread did not fix it; the owner had to open the door panel and reseat the connector.

What to checkIf a DIS15022 powers on but will not start a cycle and shows no error code, first try the cancel/reset procedure (hold Programme Selection/Programme Cancel for 3 seconds). If that fails, the likely cause is the door lock wiring connector inside the door panel working loose; reseating it is a DIY fix. A service call to diagnose a no-start typically costs a call-out fee before any part is touched.

Clogged impeller holes and filter system leave dishes unwashed (DIS15022)

Minor

This is Beko's own owner manual troubleshooting page for the DIS15022, which treats clogged impeller holes and a clogged/incorrectly installed filter as the recurring causes of poor washing. These are routine, user-fixable maintenance items rather than a defect, so severity is low.

What to checkPoor wash results on a DIS15022 are most often fixed by cleaning the impeller holes (food remnants like lemon pips) and the filter system regularly. This costs nothing but time and is the first thing to check before any paid service.
