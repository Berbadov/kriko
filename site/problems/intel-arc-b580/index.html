Intel Arc B580 Vulkan crash makes Path of Exile 2 unplayable

To check

Multiple B580 owners report the game crashing within a minute on Vulkan after a game patch, even after DDU and the latest WHQL drivers; DX12 is reportedly near-unplayable. This is a driver/game compatibility quirk, not hardware failure.

What to checkA shopper should expect that some current titles break on the B580's Vulkan path until a driver or game patch lands; verify the specific games you play before committing.

Reported onpathofexile.com

Intel Arc B580 occasional system/monitor freezes on Linux (Mesa)

To check

A Bazzite (Linux) user reports random monitor lockups/flicker on the B580 with Mesa 25.3.0. This is a Linux-driver quirk, not a hardware failure, and does not affect Windows users.

What to checkA shopper planning to run the B580 on Linux should expect possible display freezes on some Mesa builds; Windows driver issues were the more prominent reports in this run.

Reported ongithub.com

Intel Arc B580 power connector seating issue left card unrecognized

To check

One owner on Intel's own community forum reports the B580 not being recognized until he shimmed the power connector for pressure, and that wiggling it while powered caused a crash. Single-owner report in a Dell PowerEdge R730 server, so it is anecdotal and not a documented mass failure.

What to checkThis is a weak, single-source electrical report in an unusual server build; a shopper should not weigh it heavily, but should seat the power connector firmly. No widespread B580 connector-melting reports were found.

Reported oncommunity.intel.com

Minor1

Intel Arc B580 VRAM stays clocked at full speed while idle

Minor

Intel's own knowledge base confirms the B580's VRAM stays at full 2375 MHz at idle, but frames this as expected behavior and states the GPU idles under 10W once ASPM/L1/PCIe link power savings are enabled.

What to checkIdle power is not a real defect here — Intel documents it as expected and under 10W with power-saving features on — so a shopper should not treat high idle draw as a reason to avoid the card.

Reported onintel.com
