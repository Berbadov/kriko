Throttle failure triggers fault code 14 and requires part replacement

Serious

The manufacturer's own FAQ confirms fault code 14 means the throttle must be replaced. An owner on Comfy.ua confirmed it in practice: 'вчера вылезла ошибка код 14 ,отправмл по гарантии' (yesterday error code 14 appeared, sent under warranty).

What to checkIf the dashboard shows code 14 or one long + four short beeps, the throttle unit is the failing part; plan for a service-center repair or a throttle replacement (~7-15 EUR part).

Water ingress under rain triggers error code 10 and voids warranty

Serious

An owner reports error code 10 after one ride in rain; the service center rejected the warranty claim citing moisture ingress. The model is rated IPX5 (jet-water resistant, not immersion), so rain exposure is a real risk.

What to checkAvoid riding in rain; error 10 after moisture is often treated as a non-warranty case, so the fix is out-of-pocket.

Reported oncomfy.ua

Newest linked source retrieved: 2026-10-27

Worth checking1

Real-world range is overstated versus the 45 km claim

To check

Verified buyers report the advertised 45 km range is only achievable in lab conditions; realistic range is ~25-35 km depending on rider weight, mode, and terrain.

What to checkBudget for roughly 25-35 km of real range, not 45 km, especially in Sport mode or with heavier riders.
