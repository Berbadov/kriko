Arcelik 2024'te kapatma valflerindeki gaz kaçağı riski nedeniyle 3.566 fırının geri çağrılması

Ciddi

Arcelik Global'in kendi 2024 Entegre Raporu, kapatma valflerindeki yüzey kusurundan kaynaklanan gaz kaçağı riski nedeniyle 3.566 fırın ünitesinin resmi geri çağrılmasını doğruluyor. Bu, 'Arcelik ankastre set recall RAPEX' tohum sorgusundan üreticinin birincil belgeleridir.

Neye bakmalıBir alıcı, Arcelik'in kapatma valflerindeki gaz kaçağı riski nedeniyle fırınlar için 2024'te geri çağırma yayınladığını bilmelidir, bu nedenle belirli bir ünitenin etkilenip etkilenmediğini kontrol etmek güvenlik açısından önemlidir.

Arçelik OCD T 651 ES cam ocak garanti kapsamındayken pişirme sırasında paramparça oldu

Arçelik ankastre hob kullanılmadan kendi kendine tutuştu, mutfakta yangın riski

Arçelik ankastre set ocak camı pişirme sırasında kırıldı, cam aile üyelerine çarptı
