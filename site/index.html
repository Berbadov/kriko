  • Beside the listing

    The browser extension opens a panel next to the product you're reading and shows what is documented about that exact model.

  • Every finding shows its source

How it works

Set up once, then browse

  1. Install Kriko

    Run the Windows installer. No administrator rights, no Python or Node to install.

  2. Add the extension

    In Kriko, open Browser extension and follow the steps to add it to Chrome.

  3. Install a catalog

    Open Overview and press Install on the catalogs you want. They update every week.

  4. Open a listing

    Open the Kriko panel on a product page and read what is known about it.

Not covered yet? Quick look researches it with your agent. Save quick looks into a catalog and it grows from what you already found.

Any other product

Yours next

Quick look works on any product page. File what you find into a catalog, and share it as one file anyone can install.

Runs on your computer

Looking up an installed catalog works offline. Catalogs and your history stay on your machine. There is no account.

Your agent, your bill

Research uses the agent or model you choose: a coding agent you already have, a local model, or your own API key.

Open source

The app is MIT licensed. Read the code, build it yourself, or write a catalog for a category you know.
