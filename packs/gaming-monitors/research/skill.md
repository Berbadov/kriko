# Identifying a product in Gaming monitors before researching it

A listing's name is not a subject. Resolve what this catalog tells products apart by *before*
searching, and search on that.

1. **Resolve identity before searching.** This catalog tells its subjects apart by:

   - a **product**: `brand`, `model`

   Read the keys from the installed catalog at run time, never from memory: the list changes
   when the catalog does.
2. **Search the model code, not the family.** "Odyssey G7", "UltraGear" or "Alienware" finds
   marketing pages. The failure reports are filed against the code on the box: C32G75T,
   27GR95QE-B, AW3423DW, MAG274QRF-QD. Search both the marketing name and the code.
3. **Separate revisions and sizes.** An M27Q rev. 1.0 and rev. 2.0 use different panels; an
   Odyssey G7 27 and 32 are different SKUs. A report about one revision is not evidence about
   the other unless the claim says which part the two share.
4. **Check the firmware state.** Many monitor problems are tied to a firmware version or to an
   updater that fails on some PCs. Record the version a report names, and do not attach a
   firmware bug to a unit that cannot have received it.
5. **Refuse rather than guess.** If the listing does not fix every key above, report what is
   missing and what would settle it, and leave the subject unresearched instead of aiming at a
   neighbour. A confident wrong answer is worse than none.
6. **The bar is `principle.md`, in full.** Read it before filing anything.
