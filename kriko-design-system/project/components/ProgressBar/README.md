Use for run progress and pass rates: a 24-segment LED meter in a `well`, lit segments `ice` while running and `brand-bright` while waiting on the user. The head segment blinks at the loop rate while a run is in progress and stops when it finishes. Always pair with a `mono-meta` line giving percent and stage in `dim`; the `slim` variant (8px segments) fits rows.

The consumer provides the value and the stage text. Under `prefers-reduced-motion` the head does not blink.
