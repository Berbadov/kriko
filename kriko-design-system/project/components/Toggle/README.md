Use for on/off settings inside a labelled row. A 56 by 30 `well` track holds a graphite knob that slides 24px on `--ease-mech`, with a short LED slit on its face that lights `ice` when on. The row shows the setting name in `body-strong` and a `caption` in `muted`, divided from the next by `hairline`.

The consumer provides name, description, state and `role=switch` with `aria-checked`. Focus is a 2px `ice` outline offset 3px.
