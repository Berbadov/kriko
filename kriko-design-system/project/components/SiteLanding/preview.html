kriko / local product knowledge

What is written, with where.

Kriko reads the pages you allow and writes claims, evidence and sources into one SQLite file per product. It never rates, ranks or recommends.

Rules

Three it keeps

No verdictsNo scores, rankings or "best". Where sources disagree, both claims are kept and marked disputed.
Local onlyThe store, the pages and the local model stay on this machine. No account, no telemetry.
One file per productPlain SQLite. Open it with any tool, copy it, delete it. The data is yours.
