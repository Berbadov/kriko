Kriko extension

One setting: where the Kriko app is listening. Everything else the extension does — which sites it reads, what it says about a listing — comes from the packs installed in that app, not from here.

Leave it empty to use the default, http://127.0.0.1:8787. Change it only if you are running the app somewhere else — another port, or another machine on your own network. The extension talks to nothing on the internet.

If nothing answers

The address is remembered either way — an app you have not started yet is not a wrong address. Start Kriko, then press Save and test again to confirm the two ends can see each other.
