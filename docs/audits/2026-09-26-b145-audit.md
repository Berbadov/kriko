# B145 audit — every screen, 2026-09-25/26

The findings behind backlog B145. Eleven areas were walked on this Windows machine against a throwaway home (never `~/.kriko`), with stand-in agent CLIs, by one finder per area; a second agent then tried to reproduce every finding independently. What is listed here survived that: **CONFIRMED** (reproduced), **MISSED** (the verifier found it and the finder did not), or **UNCLEAR** (the verifier could not settle it — the fixer re-checks it first).

Five items were dropped as not defects: research-5 (a walk-script false positive), perf-6 and perf-m1 (confirmations that polling and route cleanup are sound), research-m1 (not reproducible twice), research-m2 (a clean result at 620x520).

Severity: **b** blocker, **M** major, **m** minor, **p** polish. Each fix commit names the finding ids it closes.
