# Concept mockups — ownership cost and decision flows (brainstorm, 2026-11-04)

AI-generated concept images for the brainstorm about moving Kriko beyond
"what goes wrong" toward the money side of buying: total cost of ownership,
depreciation, fleet decisions and procurement sign-off. These are concepts,
not shipped screens. Style follows the app: near-black `#05070F`, accent
`#1F4FFF`.

| Image | Concept |
|---|---|
| `01-tco-compare.jpg` | Compare board gains a **5-year ownership cost** row: price + sourced repair costs + consumables, per product column. |
| `02-depreciation-curve.jpg` | **Depreciation forecast**: resale value per model fitted from the listing pages the price watcher already reads; observed curve plus projection. |
| `03-fleet-view.jpg` | **My equipment** fleet list for business owners: purchase date, age, failure-risk badge, expected repair cost; banner proposes which model to standardize on. |
| `04-procurement-pdf.jpg` | **Procurement-ready export**: one-page PDF with ranked table, recommendation box and a sources appendix, for partner/accountant sign-off. |
| `05-decision-flow-mobile.jpg` | **Help me decide** on mobile: weighted sliders (price / reliability / repairability) over the "For you" preferences, one ranked pick with reasons. |
| `06-shortlist-alerts-mobile.jpg` | **Shopping shortlist** on mobile: saved products with price-drop and new-finding chips, plus the post-purchase "did it hold up?" nudge. |
| `07-supplier-check.jpg` | **Supplier check**: the listing check run across a seller's storefront or across sellers of the same SKU; trust score and ranking. |

Per the doctrine, everything category-specific here (repair costs, resale
curves, failure rates) belongs in pack data, not the engine.
