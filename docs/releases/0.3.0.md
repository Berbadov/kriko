# 0.3.0 release verification

## Publication decision

On 2026-10-22 the maintainer explicitly authorized publishing 0.3.0 with the
verification limits below documented, and accepted the unsigned Windows builds.
This is an exception to the observation requirement in
[stable release acceptance](../RELEASE_ACCEPTANCE.md). Missing observations are
not recorded as passed, and the automated publication check is not weakened.
The release is assembled and published locally from the verified Windows builds.

## Automated checks

- The full Windows gate passed: 4,404 Python tests, 28 desktop UI tests,
  460 extension tests and 12 website tests. Python also reported 22 skips.
  Version agreement, Ruff, mypy, wheel installation/import/CLI, TypeScript,
  desktop lint and Windows Rust checks/tests passed.
- Another 25 app/engine update tests passed after setting the minimum desktop
  version in the engine manifest to 0.3.0. Older desktops therefore receive the
  complete installer, including the new interface.
- The installer, portable ZIP and engine ZIP checksums were verified.
  Packaged executable and distribution metadata report 0.3.0.
- The portable archive was extracted into an isolated temporary directory.
  Its frozen engine passed health/version, extension staging, empty-store,
  benchmark data, settings API, lookup, failed-job, MCP and terminal checks.
  Its desktop process stayed running for 25 seconds and spawned its engine
  without panicking. This checks startup, not the appearance of its window.
- The frozen engine omits unused development packages: 878 files / 72.11 MiB.
  Catalog assets are built separately and indexed at immutable v0.3.0 URLs.

## Verification limits

- No visual inspection of the packaged Windows interface was possible in this
  environment. Setup, sourced answers, follow-ups, comparison, stopping jobs,
  reconnecting and retaining data across upgrades were not observed as complete
  hands-on journeys. Automated fixtures cover behavior but do not replace them.
- A fresh install/uninstall lifecycle was not run: the machine already has a
  Kriko installation, and its data and installation were preserved.
- No live provider/model research was run during this release review. Tests used
  fixtures; real provider availability, cost and answer quality remain unverified.
- Windows builds are unsigned. SmartScreen may warn before the installer opens.

These checks do not establish that every interaction is free of bugs. Report
problems with the app version, affected screen, agent/model and a redacted error;
do not include credentials or private listing data.
