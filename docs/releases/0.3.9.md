# Kriko 0.3.9 verification — Windows x64

Built locally on 2026-10-31 from `main` at `4b8e4fd8` (PRs #307, #309–#318) plus
this release commit's version bump, in a clean worktree. It follows 0.3.8 on
`main`; the extension keeps its 0.5.0 manifest (its panel colours follow the
app's new palette) and the phone app (0.10.0) is unchanged and not part of this
change.

## What changed for readers

- **Agent turns search, keep their answer, and fall back instead of failing.**
  An explicit research request in English or Turkish now takes the web turn and
  answers from the pages it read, and a product name sent alone is researched
  instead of answered from memory. A tool-less Codex or Mistral Vibe turn asks
  for the search its brief included instead of replying that the session has no
  web search, and host-read turns search through the reader's own
  DeepSeek/Exa chain rather than OpenSERP alone. A resident turn that runs out
  of clock keeps the prose it already streamed and is marked cut off instead of
  failing, a hosted session that will not open costs a 10-second start
  allowance rather than the whole turn, and the chosen agent is started while
  Kriko reads its pages (5.32 s cold start, 0.00 s on reuse, measured on this
  machine). The window's liveness check now reads a background probe: a busy
  store on a shared machine can no longer make the window call a healthy engine
  dead, and the probe never creates the store it checks.
- **The app's agent mark replaces the orb and carries the state.** The agent's
  logo tile is its whole presence: a hairline track at rest, one thin arc
  travelling the edge while it works, a slow rise and fall while it waits, an
  amber underbar and a greyed logo when paused, a mint flash and a seal through
  the middle when the answer lands, and a red underbar with one shake on
  failure. The empty chat prints Kriko's own mark as a dot field instead of a
  sphere, and the top bar's agent pill shows the same mark in the same state.
  Reduced motion, or a window that is not in front, leaves every animation as a
  still, legible frame. The window chrome around it also calmed down (neutral
  surfaces, sharper radii, readable badges), and the browser extension's panel
  and options pages use the same neutral palette, without the blue cast.
- **The public site is rebuilt on a new design layer.** Space Grotesk sets the
  display and Inter the body, both bundled locally with their OFL licences; the
  palette is neutral white and neutral charcoal in dark mode, the blue stays the
  only accent, and one 4px spacing scale calms the hero and every section. The
  hero sits on a WebGL blue aurora: a static frame under reduced motion, paused
  when the tab is hidden, DPR-capped, with a no-WebGL fallback. An audit also
  fixed filled buttons losing their text colour on the install, problems and 404
  pages.
- **The catalogs now ship as one folder beside the per-pack files.** This
  release attaches 32 `.kpack` catalogs, their `packs.json` index, and
  `packs-0.3.9.zip` holding the same 33 entries in one folder for an offline
  copy or a hand-off. The app still installs and updates one verified download
  at a time from `packs.json`; the bundle is a sibling, never a replacement.
  The installer still carries none: a fresh install starts empty and the reader
  chooses what to install.

## Checks completed

- The full gate on the release tree (version bumped to 0.3.9): `py`
  **5,127 passed and 26 skipped**, with ruff and all four mypy stages clean.
  One test failed:
  `src/app/tests/test_resident_transport.py::test_four_reader_runs_each_get_their_own_agent_process_at_once`,
  the documented contention flake, which passes alone (re-run: 1 passed). It
  failed the same way in two earlier batch runs on the merged agent branches and
  passed alone each time, so it is recorded as environmental contention under
  parallel workers, not a product failure. The Python tree is the same code as
  final `main` at `4b8e4fd8`, whose own gate had the same shape.
- The site suite on the release tree: **41 of 41 passed**, run twice end to end.
  A later repeat hit jsdom's `HTMLCanvasElement.getContext` race in the Turkish
  guide test; that test passes alone (2 passed), and no site file differs
  between those runs, so it is recorded as a jsdom/WebGL harness race, not a
  site failure.
- One earlier release-tree run also failed `test_dependencies_are_locked.py`
  because the authoring-only `[pipeline]` extra installed into that venv had
  moved `opentelemetry-api` off the pin in `requirements.lock`; restoring the
  pinned 1.45.1 makes the test pass, and the build venv installs
  `requirements.lock` itself, so the shipped closure is the locked one.
- The artifacts are built and published from this commit after the tag; their
  sizes, digests and the frozen sidecar's health answer are recorded in the
  release body and the evidence file when the build finishes.
- Extension version 0.5.0 and phone app 0.10.0 are unchanged; the extension's
  panel and options pages follow the app's neutral palette.

## Not observed

  the extracted portable copy. The installer was not run on this machine.
- A live research turn on the packed 0.3.9 engine. The routing, search, keep-
  answer and fallback changes are covered by tests and by the frozen sidecar's
  health check; the packaged build was not asked a live question.
- The extension against a live listing on the packaged app. It is covered by
  the extension and UI suites and synthetic fixtures.
- The site's browser and Playwright suites and the aurora on a real screen; the
  site tests run in the gate, and the design was reviewed on the branch.
- One run of each product; no live provider measurement was made for this
  release.

## Packaging notes

- The updater manifest (`engine.json`) reports shell 0.3.9, so an older app is
  offered the installer rather than an engine-only update.
- The installer carries no catalogs. This release attaches 32 `.kpack` files,
  `packs.json` and `packs-0.3.9.zip`.
- The installer is unsigned: SmartScreen warns on first run. Choose **More
  info**, then **Run anyway**.
- `SHA256SUMS.txt` covers the installer, portable ZIP, engine ZIP and extension
  ZIP; `SHA256SUMS-ALL.txt` covers every uploaded asset.
