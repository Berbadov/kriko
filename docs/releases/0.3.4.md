# Kriko 0.3.4 verification — Windows x64

Built locally on 2026-10-24 from `main` after PR #279 and PR #280 merged, with
the version bump on `release/0.3.4`. The maintainer asked for publication after
the 0.3.3 update did nothing on friends' machines, knowing the limits below.

## What changed for readers

- "Update now" installs the new version. Apps on 0.3.2 were offered an
  engine-only update that did nothing they could see; every app is now sent to
  the installer unless a release says an engine-only update is safe. The
  updater manifest for this release requires shell 0.3.4.
- The top bar's tabs fold to icons sooner and the agent pill hides sooner, so
  nothing runs over the logo between about 1000 and 1250 pixels.
- The catalog request box, snapshot file picker, tick boxes in Logs and the
  model store, and the fold-aways in Setup, Local model, Agents and Catalogs use
  Arc components drawn from Kriko's own colours.
- The settings icon is a clean gear.
- Extension 0.4.6: its settings page's tick boxes and round choices match, and
  the buyer card's "Also watch while my computer is off" box is a box again.

## Checks completed

- Gate stages `ui`, `node` and `py` on the Arc branch before merge: 4,561
  Python tests passed and 23 skipped; extension 514; UI 92; type check, lint
  and build passed. The `mobile`, `wheel` and `tauri` stages were not run for
  that branch: it touches none of them.
- The installer, extracted with 7-Zip, holds the app and the engine; its
  engine started in 2.1 seconds on a throwaway profile and answered
  `/api/health` with version 0.3.4, extension 0.4.6 and no catalogs.
- Demo-mode check in Chrome against the dev server: gear icon, the new
  textarea, file picker, checkboxes and fold-aways, Compare and Queue. The
  extension settings page was viewed from a static server.
- The package script finished with exit code 0.

## Not observed

- A clean install, running the installer, an upgrade from 0.3.2 or 0.3.3, and
  the extracted portable copy. The installer was not run on this machine: its
  hook stops the installed Kriko and rewrites its registration.
- The new controls and top bar in the packaged window, and at 125% scaling.
  The top-bar breakpoints were measured in an iframe at 780–1500 pixels in the
  demo.
- The extension's buyer card in a real listing page.
- Any live research: nothing in this release changes research.

## Packaging notes

- The updater manifest (`engine.json`) now requires shell 0.3.4, so a 0.3.2 or
  0.3.3 app is offered the installer.
- No catalogs ship with this release.
- SHA256SUMS.txt covers the installer, portable ZIP, engine ZIP and extension
  ZIP.
