# Kriko 0.3.6 verification — Windows x64

Built locally on 2026-10-25 from the release commit `6e6393e6` on
`feat/measured-stack` (PR #285), in a clean worktree. The maintainer asked for
publication and for the browser extension to be updated, knowing the limits
below. 0.3.5, published earlier the same day as a Preview, came from a separate
line that was never merged into `main`; this release continues from `main` and
supersedes it.

## What changed for readers

- The Kriko Agent plans its research before it searches, checks each page
  against the product named, counts what it covered and how fresh it is, and
  every desktop chat answer carries a record of the searches, the pages and the
  kinds of source behind it.
- Extension 0.5.0: a quiet panel with Compare inside it. The shortlist is the
  app's research queue; an unknown product has one Research button instead of
  three; the settings page and the tour say less.
- Mobile 0.10.0 (not part of the Windows download): a floating scanner puck you
  can drag, a tray and a bottom sheet; twenty-five Turkish strings corrected.
- kriko.cc shows new examples; the Turkish page is rebuilt from them.
- A chat test no longer races a busy machine (test change only).

## Checks completed

- The full gate on `6e6393e6`, run before any push: `py` 4,639 passed and 24
  skipped with ruff and mypy clean; `wheel`, `node` (extension 526), `ui`,
  `site` (13) and `tauri` (`cargo check` and `cargo test`, 13 passed) passed.
  Wall time 7 minutes 58 seconds.
- The frozen sidecar, before it was packed, started, printed its port and
  answered `/api/health` with version 0.3.6, extension 0.5.0 and no catalogs. A
  job for a subject that does not exist failed cleanly, MCP answered
  `initialize`, and the terminal said something back.
- The built desktop app stayed up for 25 seconds without a panic and spawned its
  engine. This was the built tree, not an installed copy.
- The installer, portable ZIP and engine ZIP were copied out of the worktree and
  their SHA-256 sums matched the build's own `SHA256SUMS.txt`.
- Pictures of the new extension panel (light and dark, idle, risks, expanded and
  the compare tray) were taken from the preview page with stubbed answers; the
  phone scanner was run on an Android emulator in English and Turkish; the website
  was captured in English and Turkish, with one capture at phone width. The
  pictures are in `docs/previews/`.
- The maintainer ran an earlier test build of this code on their own machine
  (stamped 0.3.5, before the release commit) and reported that it works well.
  What exactly was tried was not recorded.

## Not observed

- A clean install, running the installer, an upgrade from 0.3.4 or from the 0.3.5
  Preview, and the extracted portable copy. The installer was not run on this
  machine: its hook stops the installed Kriko and rewrites its registration.
- Live research on the packed 0.3.6 engine, so the agent's new plan and record
  were exercised by tests and not by a live turn on this build.
- The new panel on a real listing page in a loaded extension, and Compare
  against a running app: the pictures came from the preview page.
- The phone scanner's drag, edge snap and dimming, the light palette, and any
  real device. Only the dark palette was captured, on an emulator.
- The Chrome Web Store copy. The maintainer reported submitting
  `kriko-extension-0.5.0.zip` by hand, because the store cannot be driven from
  the browser tool. That submission was not seen here, and Google's review is
  outside this build.

## Packaging notes

- The updater manifest (`engine.json`) requires shell 0.3.6, so an app on an
  older version is offered the installer, not an engine-only update.
- No catalogs ship with this release.
- `SHA256SUMS.txt` covers the installer, portable ZIP, engine ZIP and extension
  ZIP (`kriko-extension-0.5.0.zip`: the `extension/` folder without `tests/`).
