# Kriko 0.3.8 verification — Windows x64

Built locally on 2026-10-30 from the release commit `10fc400c` on `main`
(PRs #304, #305 and the site integration #306), in a clean worktree, with the
version bumped to 0.3.8. It follows 0.3.7 on `main`; the extension (0.5.0) and
the phone app (0.10.0) are unchanged and not part of this change.

## What changed for readers

- **The Mistral agents no longer lose a turn to their own transport.** Vibe's
  hosted tool-less session was answering `session/new` with `[WinError 5]
  Access is denied` on Windows; a pre-delivery rejection, a slow handshake or a
  missing `vibe-acp` now runs the prompt as a fresh process instead, and a
  failed session is skipped for ten minutes. An explicit `persistent` choice
  still reports the failure, and a delivered turn is never replayed.
- **The Mistral API agent searches when its own connector does not.** When a
  reply carries no query and no source, Kriko searches through its own
  Exa/Tavily/DeepSeek provider and grounds the answer on that text; the API
  timeout is now 240 s. The model picker carries the current Mistral ids and
  prices (Mistral Large 4, Medium 3.5, Small 4, Ministral 3).
- **Product findings are inline, with costs and freshness.** Listing audits
  highlight findings with hover/focus explanations and quick-check buttons;
  result cards carry risk badges; right-click scans a product link or selected
  text. Saved checks show source dates and a staleness threshold, quote
  repair/part costs, re-research through the existing job pipeline, and export
  a standalone HTML report (printable to PDF). Costs stay source quotes; no
  failure probabilities or currency conversions are invented.
- **The public site reads better and is machine-readable.** The Geist redesign
  (dawn halos and grain) is in, a touch screen is offered a `mailto:` that
  carries the install page to a computer, and every product page declares an
  `Article` with its citations and a two-question `FAQPage`. `llms.txt` is
  generated from the pages that exist, and `robots.txt` names the search and
  answer crawlers.

## Not observed

- A clean install, running the installer, an upgrade from 0.3.7 or earlier, and
  the extracted portable copy. The installer was not run on this machine.
- A live research turn on the packed 0.3.8 engine. The Mistral fallbacks are
  covered by tests and the frozen sidecar's health check; the packaged build
  was not asked a live question.
- The extension's new inline/cost/report features against a live listing on the
  packaged app. They are covered by the extension and UI suites and synthetic
  fixtures.
- One run of each product; no live provider measurement was made for this
  release.

## Packaging notes

- The updater manifest (`engine.json`) reports shell 0.3.8, so an older app is
  offered the installer rather than an engine-only update.
- No catalogs ship with this release.
- The installer is unsigned: SmartScreen warns on first run. Choose **More
  info**, then **Run anyway**.
- `SHA256SUMS.txt` covers the installer, portable ZIP and engine ZIP.
