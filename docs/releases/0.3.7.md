# Kriko 0.3.7 verification — Windows x64

Built locally on 2026-10-25 from the release commit `0197f5c2` on
`feat/scope-before-search` (PR #286), in a clean worktree. The maintainer asked
for the fix and for it to be released. It follows 0.3.6 on `main`; the
extension (0.5.0) and the phone app (0.10.0) are unchanged and not part of this
change.

## What changed for readers

- A Quick Look sizes its search to the product. Before it searches, the Kriko
  Agent takes one short look at what the product is and which parts of it need
  their own evidence; a car gets up to twelve retrievals and ten findings, a
  watch keeps the usual budget. Each finding is tagged with its part, and the run
  log says which parts came back with a sourced finding. If that look cannot be
  made, the search runs as it did before.
- A finding is no longer lost because the agent retyped the page address. The
  quote is found on the page that carries it; a quote on no page it read is still
  refused.
- A cut-off answer is no longer thrown away. The ceiling is doubled (four times
  for a whole catalog), and a Quick Look or catalog job that is still cut off
  keeps what was written. A cut-off catalog is now repaired and read.

  stored products of earlier jobs (from source, not from the packed build):
  a keyboard went from 1 kept and 4 dropped to 6 kept and 0 dropped; a watch
  from 2 kept and 1 dropped to 4 and 0; a car from three findings, all one

- The frozen sidecar, before it was packed, started, printed its port and
  answered `/api/health` with version 0.3.7, extension 0.5.0 and no catalogs.
- The built desktop app stayed up for 25 seconds without a panic and spawned its
  engine. This was the built tree, not an installed copy.
- The installer, portable ZIP and engine ZIP were copied out of the worktree and
  their SHA-256 sums matched the build's own `SHA256SUMS.txt`.
- `kriko-extension-0.5.0.zip` was compared file by file with the `extension/`
  folder of this tree (28 files, no differences) and is the same archive that
  accompanied 0.3.6.

## Not observed

- A clean install, running the installer, an upgrade from 0.3.6 or earlier, and
  the extracted portable copy. The installer was not run on this machine: its
  hook stops the installed Kriko and rewrites its registration.
- A live research turn on the packed 0.3.7 engine. The scope step, the address
  fix and the larger ceiling were observed from source against the live provider
  and covered by tests; the packaged build was not asked a question.
- Catalog authoring against the live model with the larger ceiling. The repair of
  a cut-off catalog is covered by tests on recorded and constructed replies.
- One run of each product, so the counts above show a direction, not a rate. The
  television still dropped one finding, which was not investigated.
- The extension against a running 0.3.7 app, and the phone app, neither of which
  changed.

## Packaging notes

- The updater manifest (`engine.json`) requires shell 0.3.7, so an app on an
  older version is offered the installer, not an engine-only update.
- No catalogs ship with this release.
- `SHA256SUMS.txt` covers the installer, portable ZIP, engine ZIP and extension
  ZIP (`kriko-extension-0.5.0.zip`: the `extension/` folder without `tests/`).
