# Kriko 0.3.13 verification

Cut from `main` at the merge of #342 (dead scratch removal) and #343 (the
`create_app`/`run_turn` god-function split), on top of the 0.3.12 release
commit, plus the work below. The extension keeps its 0.5.0 manifest; the
website and the phone app live in their own repositories.

## What changed

- Type: Inter (body, one weight step heavier) and Chivo Mono (titles), both
  bundled via `@fontsource-variable`; Geist and Inter Tight removed.
- Opt-in query sharing: `share_queries` setting (default off), the Settings >
  About checkbox, and `src/app/queryshare.py`. Sends only `q` (lowercase brand
  and model), `outcome`, and for a hit `report` and `category`, to the
  gateway's anonymous `POST /v1/queries`; no `Authorization`, no timestamp, no
  id; in-memory queue; cleared when turned off.
- NLI evidence gate: `src/app/nli_gate.py`, applied in
  `categorypack.ground` and `findings.accept_findings`. Optional `nli` extra
  (torch, transformers) excluded from the frozen sidecar; off when absent.
- `chat.run_turn` is now a `_Turn` class (named methods instead of eight
  nested closures over shared state); the public signature is unchanged.
- `web/app.py::create_app` is now a short orchestration over
  `_register_routers`, `_start_core_state`, `_install_middleware_and_routes`;
  middleware order is pinned by `test_origins.py`.
- Removed dead scratch: `tools/bench_agent_transport.py`, `bench_endpoints.py`,
  `bench_startup.py`, `check_scenarios.py`, `compare-configuration.py`,
  `trace_processes.py`, `try_claim_extractor.py`, `tools/local_scenarios.json`,
  `packaging/macos_icon.py`, `packaging/smoke_firefox.py`, and the committed
  `.vibe/` session screenshots (`.vibe/` is now gitignored).

## What was and was not observed

See `0.3.13.json`. On the final tree: ruff and mypy are clean, the `kriko-ui`
lint, build and 123 node tests pass, and the full Python suite ends with 17
failures that are not from this release: 15 fail identically on a clean
`origin/main` (the network-dependent agent bench and failure-class tests, and a
version test that reads stale installed metadata) and 2 are load flakes that
pass alone.

The Windows installer, portable ZIP and engine ZIP were built with
`kriko-ui/package.ps1` from a clean worktree of this source, and the build's own
checks passed: the frozen engine's handshake and a served request, the app
staying up for 25 seconds with its engine spawned, and the portable archive.
The installer was not installed and no reader journey was walked on a packaged
window, so `tools/release_readiness.py` still refuses complete stable
certification, as it did for 0.3.10-0.3.12. No macOS disk image was built.
The 32 catalogs, `packs.json`, `packs-v0.3.13.zip` and the unchanged extension
ZIP are attached beside the installer.
